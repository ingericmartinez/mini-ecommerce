Portal de Documentación de la API de E-Commerce

Bienvenido. Esta API RESTful permite gestionar el catálogo, clientes, pedidos y proveedores para un sistema de comercio electrónico.

Recursos

  • Swagger UI: http://localhost:8080/swagger-ui.html
  • OpenAPI JSON: http://localhost:8080/v1/api-docs
  • Consola H2: http://localhost:8080/h2-console

Para conectar en H2 Console usa:

  • JDBC URL: jdbc:h2:mem:testdb;MODE=MySQL;DATABASE_TO_LOWER=TRUE;DEFAULT_NULL_ORDERING=HIGH;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE
  • User Name: sa
  • Password: (dejar vacío)

Si ves una URL por defecto como jdbc:h2:~/test, reemplázala por la anterior para evitar el error de base de datos de archivo no encontrada.

Seguridad y CORS

  • La seguridad está activada. Autenticación: HTTP Basic.
  • Usuarios de prueba: user/user123 (rol USER) y admin/admin123 (rol ADMIN).
  • Las solicitudes GET a /api/v1/ecommerce/** son públicas. Operaciones de escritura (POST/PUT/PATCH/DELETE) requieren autenticación.
  • CORS habilitado para http://localhost:5173 y http://127.0.0.1:5173 (Vite).
